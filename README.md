# Presence-3DS Backend
This project is part of the [Presence-3DS](https://github.com/3ds-presence/) project.

Backend of the Presence-3DS project. It handles all the features of the API, including Discord authentication, refresh tokens, and link with Discord Gateway for Rich Presence.

The 3ds connects to the backend API to transfer the current game to [Activity-Generator](https://github.com/3ds-presence/Activity-Generator), the Activity-Generator then generates the activity and sends it to the backend, which then sends it to Discord.
